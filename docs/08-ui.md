# 08 · Interface

Mobile-first, tema escuro, PWA instalável. O app é usado no campo, com sinal
ruim e uma mão só.

## Tema white-label

A paleta default é a do app de referência:

```
bg #0a0d0a · card #12180f · card2 #18220f · linha #26331b
texto #e8f3ea · muted #93b29b · accent #22c55e · accent2 #16a34a
ouro #ffd700 · prata #c0c8d0 · bronze #cd7f32 · perigo #ef4444
```

Os tokens vivem em CSS vars. `applyTheme()` troca `--accent` e `--accent2` pela
cor primária do tenant; o resto do tema deriva. Nome, slogan, escudo e link do
Instagram também são por tenant, assim como os nomes dos times (default
Branco/Preto).

## Nomes na tela

Ranking e artilharia usam `buildDisp` — primeiro nome, desambiguado quando
repete. É como o grupo se chama, e é o que cabe numa tela de 420 px sem cortar.
O nome completo fica no `title`.

## Imagem compartilhável

Canvas 2D puro, sem biblioteca: 900 × ~1900 px para a escalação, 900 × 1100 para
o card do craque. `canvas.toBlob` → `navigator.share({ files })` no mobile, com
download como fallback no desktop. Jogador fora de posição sai com aro dourado.

Também há o texto para colar no WhatsApp (`lineupText`), no formato do original.

> Melhoria pendente (8.9 da spec): gerar o card no servidor com Satori/Resvg
> garante fonte e emoji iguais em todo aparelho. O canvas client-side quebra em
> Android antigo.
